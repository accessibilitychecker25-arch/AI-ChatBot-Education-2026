# AI-ChatBot-Education-2026
A web-based accessibility tool designed to help Auburn University users identify and improve accessibility issues in PowerPoint presentations, aligned with WCAG 2.1 Level AA requirements and focused on clear feedback and usability.


# Dependencies Installation

Below are the commands to download and install the required dependencies for this branch of the tool.

## Install Core AI Dependencies

```bash
pip install transformers>=4.35.0
pip install torch>=2.0.0
pip install pillow>=10.0.0
```

Or all at once:

```bash
pip install transformers>=4.35.0 torch>=2.0.0 pillow>=10.0.0
```
